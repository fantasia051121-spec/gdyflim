# 光大远薄膜官网 · 上线与运维详细教程

> 适用对象：网站所有者 / 运营人员（不需要会写代码也能完成上线和日常改内容）
> 项目现状：已开发完成一套 **7 语言（英 / 中 / 越 / 泰 / 印尼 / 马来 / 阿拉伯）** 的企业官网，带 AI 业务助手、新闻博客、可视化后台、AI 自动发文。
> 技术栈：Next.js 15 + next-intl + Tailwind + TypeScript，部署平台推荐 Vercel。

## 1. 本地查看网站（你自己电脑上）

### 1.1 安装 Node.js（只需装一次）
- 去官网 <https://nodejs.org> 下载 **LTS 版本**（推荐 20.x）。
- 一路下一步安装。装完打开"终端 / 命令提示符"，输入下面命令确认成功：
  ```bash
  node -v      # 应显示 v20.x 或更高
  npm -v       # 应显示 9.x 或更高
  ```

### 1.2 安装依赖（每个新电脑第一次需要）
进入项目文件夹（就是包含 `package.json` 的那个文件夹），执行：
```bash
npm install
```
> 会联网下载依赖，首次约 1–3 分钟，成功后文件夹里会多出 `node_modules`。

### 1.3 启动网站
```bash
npm run dev
```
看到 `▲ Next.js` 和 `Local: http://localhost:3000` 就成功了，**别关这个窗口**。

### 1.4 打开浏览器看（地址表）

| 页面 | 地址 |
|---|---|
| 英文首页（默认） | `http://localhost:3000/en` |
| 中文首页 | `http://localhost:3000/zh` |
| 越南语 | `http://localhost:3000/vi` |
| 泰语 | `http://localhost:3000/th` |
| 印尼语 | `http://localhost:3000/id` |
| 马来语 | `http://localhost:3000/ms` |
| 阿拉伯语（从右往左排版） | `http://localhost:3000/ar` |
| 管理后台 | `http://localhost:3000/en/admin`（其它语言把 `en` 换成对应代码） |

> 直接访问 `http://localhost:3000/` 会自动跳转到英文首页。

### 1.5 想看"上线后真实效果"
开发模式适合改东西，生产模式更接近线上：
```bash
npm run build     # 打包（约 1–2 分钟）
npm start         # 启动生产服务器，同样开 localhost:3000
```

```
gdy-website/
```

## 3. 把网站上到公网（部署）—— 最详细版

整体流程：**代码存到 GitHub → Vercel 拉代码自动部署 → 填环境变量 → 绑域名**。

> 域名可以先不买。Vercel 会免费送你一个 `你的项目名.vercel.app` 的地址，足够先验收效果。

### 3.1 准备账号（免费）
- 一个 **GitHub** 账号：<https://github.com>（用来存代码，Vercel 从这儿拉）
- 一个 **Vercel** 账号：<https://vercel.com>（用 GitHub 账号直接登录最方便）
- 一张能付小额费用的卡（买域名用，约 ¥50–100/年；Vercel 本身免费额度够用）

### 3.2 步骤一：在 GitHub 新建仓库
1. 登录 GitHub → 右上角 **"+"** → **New repository**。
2. Repository name 填 `gdy-website`（随便起，记得住就行）。
3. 选 **Public**（公开，Vercel 免费版要求公开；代码不含密钥，安全）。
4. **不要**勾选 "Add a README"（我们本地已有文件）。
5. 点 **Create repository**。
6. 创建后会看到一个类似 `https://github.com/你的用户名/gdy-website.git` 的地址，复制备用。

### 3.3 步骤二：把本地代码推送到 GitHub
在项目文件夹打开终端，依次执行（把 `你的用户名` 换成你的 GitHub 用户名）：

```bash
# 1) 初始化（只需一次）
git init
git branch -M main

# 2) 把文件加入暂存（node_modules、.next、.env.local 已被 .gitignore 自动排除）
git add .

# 3) 提交
git commit -m "光大远官网初始版本"

# 4) 关联远程仓库（换成你自己的地址）
git remote add origin https://github.com/你的用户名/gdy-website.git

# 5) 推送到 GitHub
git push -u origin main
```
> 推送时可能让你输入 GitHub 账号密码——**现在 GitHub 不支持密码登录**，要用 **Personal Access Token（PAT）** 当密码。生成方法见 3.5 节第 4 点，或访问 <https://github.com/settings/tokens> 生成一个有 `repo` 权限的 token。
>
> 嫌命令行麻烦？可装 **GitHub Desktop**（<https://desktop.github.com>）图形化操作，同样能完成"提交 + 推送"。

### 3.4 步骤三：用 Vercel 部署
1. 打开 <https://vercel.com> → 用 GitHub 登录。
2. 点 **Add New → Project** → 找到 `gdy-website` 仓库 → **Import**。
3. Framework Preset 会自动识别为 **Next.js**（不用改）。
4. 先 **不要** 急着 Deploy——先点 **Environment Variables** 把变量填了（见 3.5），填完再 Deploy。
5. 点 **Deploy**，约 1–2 分钟，出现 🎉 就上线了，Vercel 会给一个 `xxx.vercel.app` 地址。

### 3.5 步骤四：配置环境变量（最重要，否则部分功能失效）
在 Vercel 项目 → **Settings → Environment Variables** 里，逐条 **Add** 下面这些（Name 填左边，Value 填右边）。也可在首次 Deploy 前那一页一起填。

| 变量名 | 值 | 说明 / 在哪里找 |
|---|---|---|
| `LLM_API_KEY` | `sk-你的DeepSeek密钥` | 你已有的 DeepSeek key。⚠️ 账户需有余额 |
| `LLM_BASE_URL` | `https://api.deepseek.com/v1` | 默认 DeepSeek，一般不动 |
| `LLM_MODEL` | `deepseek-chat` | 默认模型，一般不动 |
| `ADMIN_PASSWORD` | `你自己设的强密码` | **必须设！** 后台 `/admin` 登录用，例如 `Gdy@2024!` |
| `GITHUB_TOKEN` | `ghp_xxx`（PAT） | 见下方第 4 点，AI 发文推仓库用 |
| `GITHUB_REPO` | `你的用户名/gdy-website` | 第 3.2 步的仓库名 |
| `GITHUB_BRANCH` | `main` | 默认分支，填 `main` |

**第 4 点：怎么生成 `GITHUB_TOKEN`（PAT）**
1. 登录 GitHub → <https://github.com/settings/tokens> → **Generate new token → Fine-grained 或 Classic**。
2. 取个名字，Expiration 选 `No expiration`（或定期换新）。
3. 权限勾 **repo**（全部仓库读写）或只选你的 `gdy-website`。
4. 生成后**立刻复制**那串 `ghp_...`，只显示这一次。
5. 把它填到 Vercel 的 `GITHUB_TOKEN` 变量里。

> 本地调试时，把同样的值写进项目里的 `.env.local`（参考 `.env.example` 格式）即可，`.env.local` 不会上传，安全。

### 3.6 步骤五：购买域名并绑定（可选但推荐）
1. 买域名：阿里云 <https://wanwang.aliyun.com>、腾讯云 <https://dnspod.cloud.tencent.com>、或 Namecheap / GoDaddy。建议 `.com` 或目标国别后缀（做东南亚可加 `.com.vn` / `.co.th` 等）。
2. 在 Vercel 项目 → **Settings → Domains** → 输入你买的域名（如 `gdyfilm.com`）→ **Add**。
3. Vercel 会告诉你需要在域名服务商后台添加的 **DNS 解析记录**（通常是两条 A 记录指向 `76.76.21.21`，或一条 CNAME 指向 `cname.vercel-dns.com`）。
4. 去你的域名服务商后台 → DNS 解析 → 按 Vercel 给的记录添加 → 保存。
5. 等 10 分钟～几小时（最多一天）后，状态变绿，用你的域名就能访问了。
6. 建议同时把 `www.gdyfilm.com` 也加进去并设为主域名的重定向。

### 3.7 步骤六：验证上线
- 打开你的域名（或 `xxx.vercel.app`），确认中英文首页、导航、新闻、联系页都正常。
- 打开 `/en/admin`，用 `ADMIN_PASSWORD` 登录，确认能进后台。
- 之后**每次改代码推到 GitHub，Vercel 会自动重新部署**，无需手动操作。

## 4. 上线后日常维护（不用写代码）

### 4.1 用可视化后台（强烈推荐）
访问 `你的域名/en/admin` → 输入 `ADMIN_PASSWORD` 登录。后台标签页：

| 标签页 | 能改什么 |
|---|---|
| **公司信息** | 公司名、简介、地址、电话、邮箱、社媒链接、微信号 |
| **产品 / 案例 / 首页** | 首页区块文案、产品列表、成功案例 |
| **常见问题 FAQ** | 增删问答（支持 7 语言） |
| **新闻发文** | 填主题 + 选分类 → AI 一键生成 7 语言文章并发布 |

> 改完点保存：若已配 `GITHUB_TOKEN`，会自动推到 GitHub 触发 Vercel 重建；若没配，则只改本地文件（需你手动推一次才生效）。

### 4.2 直接改文件（适合大改或批量）
用任意文本编辑器打开项目里的文件：

- **公司信息** → `content/company.json`
- **常见问题** → `content/faq.json`
- **新闻文章** → `content/news/` 目录下，复制 `_TEMPLATE.md` 改一份新的。每篇文章的 frontmatter 含 `slug / date / category / cover / source`，正文按 `title / excerpt / body` 分 7 语言填写。

改完保存 → 推送到 GitHub（见 3.3）即可上线。

### 4.3 看网站访问数据（Vercel Analytics，免费）
1. Vercel 项目 → **Analytics** 标签 → 按提示 **Enable**（免费版够用）。
2. 开启后能看到：总访问量、各页面浏览人次、访客国家/语言、设备类型等——直接回答你"哪个板块看的人最多"。
3. 想看更细（如按钮点击），后续可加 Vercel Web Analytics 的事件追踪，找我加。

### 4.4 AI 自动发文流程
后台「新闻发文」页 → 输入主题（如"PET 保护膜在新能源电池中的应用"）→ 选分类（公司动态 / 行业资讯）→ 点生成 → 系统调用 DeepSeek 产出 7 语言文章 → 自动提交上线。
> 前提是 `LLM_API_KEY` 有余额 + `GITHUB_TOKEN` 已配。

## 5. 添加新功能 / "小程序"

先分清你要的是哪一种：

**A. 在官网里加新板块 / 新页面 / 新组件**（最常见）
比如"客户案例视频墙""在线询价表单""产品下载中心""多语言 SEO 优化"等。
- 纯文案 / 板块调整：后台 + `src/messages/*.json` 语言文件即可。
- 新页面：在 `src/app/[locale]/` 下新建一个 `page.tsx` 并补对应语言文案。
- 新交互组件：放 `src/components/` 下复用。
- **最省事的做法：直接告诉我"想加什么"，我来写并接进现有 7 语言框架**，你只管验收。

**B. 微信小程序（独立 App）**
这是另一套技术（微信开发者工具 + 小程序前后端），和这个网站是**分开的项目**。如果你要面向国内客户做下单/售后小程序，我可以单独帮你规划搭建，但通常建议先把官网稳住、用官网承接海外询盘，再上小程序。

## 6. 常见问题排查

| 现象 | 可能原因 | 解决办法 |
|---|---|---|
| 本地 `npm run dev` 卡住 / 报错 | 依赖没装或 Node 版本太低 | 重跑 `npm install`；升级到 Node 20 LTS |
| 后台 `/admin` 登录失败（401） | 没设 `ADMIN_PASSWORD` 或密码错 | Vercel/本地补 `ADMIN_PASSWORD` 变量 |
| AI 聊天答非所问 / 很简短 | DeepSeek 余额不足，走了降级模板 | 给 DeepSeek 账户充值，无需改码 |
| AI 写新闻报错（502） | 同上，余额不足 | 充值 |
| 改了内容网站没更新 | 没推 GitHub，或 Vercel 没自动部署 | 确认 `git push` 成功；去 Vercel 看 Deployments 是否成功 |
| 域名打不开 | DNS 没生效 / 记录填错 | 等几小时；核对 Vercel Domains 给的记录 |
| 阿拉伯语页面排版乱 | 需 RTL，已自动处理 | 正常无需处理；如异常找我 |

## 7. 安全与密钥管理

- **`.env.local` 永不提交、永不发给别人**（已被 `.gitignore` 排除）。
- 密钥曾出现在聊天记录里 → 建议充值后到 DeepSeek 后台**轮换一个新 key**，并更新 Vercel 的 `LLM_API_KEY`。
- `ADMIN_PASSWORD` 设强密码，别用生日/123456。
- `GITHUB_TOKEN` 只给 `repo` 权限、只绑这个项目；泄露了立刻去 GitHub 撤销重发。
- 定期（如每季度）检查 Vercel 的 Deployments 和 Analytics 有无异常。
